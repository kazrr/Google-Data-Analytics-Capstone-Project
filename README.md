# Case study: How does a bike-share navigate speedy success?

### Introduction 
  Welcome to the Cyclistic bike-share analysis case study! In this case study, you work for a fictional company, Cyclistic, along with some key team members. 
  To answer the business questions, follow the steps of the data analysis process: Ask, Prepare, Process, Analyze, Share, and Act. 
  Along the way, the Case Study Roadmap tables — including guiding questions and key tasks — will help you stay on the right path.

### Scenario
  The marketing director of Cyclistic, a Chicago-based bike-share company, believes the company’s future success depends on maximizing the number of annual memberships. 
  Therefore, your team wants to understand how casual riders and annual members use Cyclistic bikes differently. 
  From these insights, your team will design a new marketing strategy to convert casual riders into annual members. 
  But first, Cyclistic executives must approve your recommendations, so they must be backed up with compelling data insights and professional data visualizations.

### Ask
  Three questions will guide the future marketing program: 
  1. How do annual members and casual riders use Cyclistic bikes differently?
  2. Why would casual riders buy Cyclistic annual memberships?
  3. How can Cyclistic use digital media to influence casual riders to become members?

### Prepare
  Before processing and cleaning the data, we will look at where the data is coming from and what it represents. The data is stored in an Amazon Web Services server with data going back to the early 2000s. The data used for this project is from Q1 to Q4 2019. While the data is outdated, it can still be used for key performance indicators to look out for in future data analysis. While all of the spreadsheets do not have the exact naming schemes for each column, each column can be generalized into the naming conventions below. 

  * Trip id
  * Rental id
  * Start time (Date and Time)
  * End time (Date and Time)
  * Bike id
  * Ride Duration (seconds)
  * Start Station id
  * Start Station Name
  * End Station id
  * End Station Name
  * Membership Type
  * Gender
  * Member Birthday

### Process / Cleaning
  To process and clean the data I followed the process below:
  1. Trim cells
  2. Remove duplicates
  3. Remove data with blank trip id's, rental id's, or start and end times.
  4. Standardize ride length to hh:mm:ss format
  5. Standardize start and end date to mm/dd/yyyy

### Analyze 
  To analyze the data, there are a few calculations for casual riders that need to be made to answer the main question: How to get casual customers to purchase memberships? 
  * Average ride length
  * Maximum ride length
  * Popular riding day
  * Time of day when the most rentals occur per hour

### Conclusions
   The data shows that members typically rent more bikes throughout the year for shorter periods. which can mean that members use the bikes as primary transportation to go short distances around their neighborhood or for their daily commute. While casual customers use the rentals for leisure weekend use, typically for over 30 minutes to 45 minutes. Maybe to visit landmarks around the city or to get near public transportation.
